# VSLive! Microsoft AI Hackathon 2026

Build real AI with Microsoft Copilot, Azure OpenAI, and .NET.

The **VSLive! Microsoft AI Hackathon 2026** is an in-person innovation challenge for developers building real-world, enterprise-ready AI solutions using Microsoft’s modern AI stack. Participants will design and deliver secure, scalable applications powered by Azure OpenAI, Microsoft Copilot, AI agents, and .NET.

Compete for **up to $25,000 in cash prizes**.

## Why This Hackathon Matters

AI is rapidly reshaping how applications are built, but knowing what is possible is not enough. This hackathon focuses on how AI is implemented inside modern Microsoft environments.

Projects are judged the way real enterprise software is judged:

- Architecture and design
- Security and safety
- Relevance to real business problems
- User experience and execution

This is a hackathon for developers who ship.

## Challenge Categories

Participants must declare a primary category and may also declare a secondary category.

### Best Azure OpenAI / LLM-Powered App

Build an application that uses Azure OpenAI, GPT models, or LLM orchestration to solve a real-world problem.

### Best Microsoft Copilot Integration

Create a compelling, practical integration using Microsoft Copilot, Copilot Studio, or Copilot APIs.

### Best AI Agent or Workflow Automation

Design autonomous or semi-autonomous AI agents that streamline workflows using Microsoft tools.

### Microsoft .NET Powered Business Applications

Develop APIs, services, productivity tools, or workflow applications built on .NET and the Microsoft ecosystem.

### Creative Applications

Explore creative uses of AI and Microsoft technologies, including content generation, image creation, games, or interactive experiences.

## Judging Criteria

Projects will be evaluated across these criteria:

- Relevance to the problem
- Architecture and design
- Safety and security considerations
- Creativity and originality
- User experience
- Additional considerations

Judging categories may be refined based on peer review and feedback.

## How to Join

### Conference Attendees

Add the Hackathon to your VSLive! @ Microsoft conference package during registration. Participation is free for registered conference attendees.

### Community Attendees: Hackathon Only

A Hackathon-only package is available for community participants for **$50**.

This is an in-person event and will not be available virtually. Spots are limited.

## Schedule

### Night 1: Kickoff and First Sprint

- Welcome and hackathon kickoff
- Team formation and idea matching
- Idea pitching and planning
- First coding sprint
- Mentor check-ins

### Night 2: Build and Submit

- Final coding sprint and project build-out

## Participation Rules

- Solo entries are welcome.
- Teams may include up to 4 people.
- All team members must register individually.
- Participants may form a team during registration or be matched with other participants looking for a group.
- Projects must be started at the event.
- Existing libraries and frameworks may be used.
- All assets and dependencies must be properly licensed.
- Full guidelines and judging criteria will be published closer to the event.

## Eligibility

The hackathon is open to registered VSLive! @ Microsoft HQ attendees and a limited number of community participants.

Exhibitors, speakers, employees or contractors of Microsoft, and sponsors are not eligible to participate in the VSLive! Microsoft AI Hackathon.
